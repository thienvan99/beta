# Solar System texture sources

These local, web-sized textures are visual reference assets. They do not represent live imagery or real-time planetary positions.

- `earth-blue-marble-2048.png` — NASA Earth Observatory, Blue Marble composite: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.png
- `moon-lroc-color-2k.jpg` — NASA Scientific Visualization Studio CGI Moon Kit, derived from Lunar Reconnaissance Orbiter data: https://svs.gsfc.nasa.gov/4720

NASA source and credit guidance should be retained if these assets are redistributed outside this project.
